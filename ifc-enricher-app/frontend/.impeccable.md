# Design Context

## Target Audience
BIM managers, structural engineers, and sustainability consultants in the European construction industry. They work with large IFC models daily and need to enrich them with material data for EU Digital Product Passport compliance.

## Use Cases
1. Upload an IFC building model, explore it in 3D, and click elements to inspect properties
2. Search the buildingSMART Data Dictionary (bSDD) for standardized materials and assign them to elements
3. Export an enriched IFC file with proper material assignments
4. Generate a material inventory report answering "how much concrete is in this building?"

## Brand Personality / Tone
**Professional engineering tool with Dutch precision.** Think: Rijkswaterstaat infrastructure software meets modern data visualization. Confident, functional, no-nonsense — but with enough craft to feel premium rather than bureaucratic. The tool handles serious data (EU regulation compliance) but should feel approachable, not intimidating.

## Aesthetic Direction
**Industrial-precision meets data-clarity.** Clean sight-lines like a well-organized engineering drawing. High information density without clutter. The 3D viewer is the hero — everything else supports it. Think: dark interface like professional 3D/CAD tools (Blender, Rhino) but with warm accents and excellent typography that signals "this was made by people who care about craft."

## Constraints
- React + TypeScript + Vite
- No CSS framework beyond what's in styles.css (no Tailwind in the build — inline/CSS only)
- The 3D viewer is an iframe and cannot be restyled
- Must work on desktop; mobile is not a priority
- Hackathon demo — needs to look impressive on a projector
