## Important debugging history
### Asset / serving bugs already fixed
These were real and are now fixed:
- worker path originally pointed at `/node_modules/...`
- wasm path issues caused HTML to be returned instead of wasm
- `.mjs` MIME type was wrong
- custom nginx MIME config accidentally made `/` return `application/octet-stream`
- frontend later switched from nginx to Caddy
- Caddy route order briefly broke `POST /api/upload` with 405 until fixed

### Remaining viewer behavior issue
Large-coordinate/far-from-origin warnings were observed, e.g.:
- `Fragments: Object ... is more than 100000 meters away from the origin and will be skipped.`

This may still matter for geometry/selection completeness, though the immediate blank-screen class of errors was resolved enough for the IFC to load.
